# Wiring up the Quick Note widget (manual, one-time, in Xcode)

This directory holds a Widget Extension's Swift source, committed as plain
files rather than generated — `src-tauri/gen` (the Xcode project) is
gitignored and gets regenerated by `tauri ios init`, and Tauri's mobile
tooling has no built-in way to add extra build targets like a widget
extension. Adding one means editing the generated `.pbxproj`, which isn't
something to script blind without Xcode open to verify it. So: a short manual
setup, once per machine/checkout.

## Steps

1. If `src-tauri/gen` doesn't exist yet, run `npx tauri ios init`. Confirm
   `npx tauri ios dev` builds and runs the app normally first — the widget
   step assumes a working baseline.

2. Open `src-tauri/gen/apple/mdcmd.xcodeproj` in Xcode.

3. **File → New → Target… → Widget Extension.** Name it `MdcmdWidget`.
   Uncheck "Include Configuration Intent" (this widget is static — no
   per-instance configuration).

4. Xcode will scaffold placeholder Swift files and its own `Info.plist` for
   the new target. Delete those placeholders, then drag the three files from
   this directory into the `MdcmdWidget` group in Xcode instead:
   - `MdcmdWidgetBundle.swift`
   - `MdcmdWidget.swift`
   - `Info.plist` (when adding, make sure Xcode sets this as the target's
     Info.plist under Build Settings → Packaging → Info.plist File, replacing
     whatever path it scaffolded)

   Make sure target membership for all three is **MdcmdWidget only**, not the
   main app target.

5. No entitlements, no App Group, no capabilities needed — this widget is a
   static "always show the same tile" launcher with no shared state (see the
   comment at the top of `MdcmdWidget.swift` for why).

6. Build & run the `MdcmdWidget` scheme once on its own to confirm the
   extension compiles and the widget preview renders. Then build/run the main
   `mdcmd` scheme, and long-press the Home Screen → **+** → find "MdcmdWidget"
   → add the small size.

7. In the app, pin a file (if not already), then tap the new lightning-bolt
   button next to it in the Shortcuts list to set it as the Quick Note
   Target. Tap the Home Screen widget — the app should launch/foreground
   straight into that file with the cursor at the end and the keyboard up.

## If something doesn't work

- **Widget doesn't appear in the gallery**: the extension probably didn't
  build — check the `MdcmdWidget` scheme's build log directly.
- **Tapping the widget just opens the app to wherever it last was, not the
  target file**: check `Info.plist` under `src-tauri/gen/apple/mdcmd_iOS/`
  actually has a `CFBundleURLTypes` entry for the `mdcmd` scheme — it's
  patched in automatically by `src-tauri/scripts/patch-ios-plist.mjs` on
  every `tauri ios dev`/`build`, but only if that script runs (it's wired
  into `beforeDevCommand`/`beforeBuildCommand` in `tauri.conf.json`).
- **Opens the target file but doesn't focus/jump to the end**: likely a
  timing issue in `MarkdownEditor.tsx`'s `focusAtEndFor` handling — check the
  browser/webview console for errors from the `quick-note-requested` listener
  in `App.tsx`.
